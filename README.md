## Overview

DNS Preview Tool combines website previewing with DNS cache support in a small, browser-based utility. It helps users inspect how a newly launched or modified website may appear while DNS changes are being evaluated.

The tool is suited to website launches, domain migrations, and everyday network troubleshooting. When an updated site is not yet visible because of resolver or local cache data, its command generator offers a starting point for refreshing the DNS cache.

## How to Use

1. Start DNS Preview Tool in your browser.

3. Inspect the resulting website preview.
4. Open the DNS cache command generator if DNS information needs to be refreshed.

6. After the cache operation finishes, check the website again.

Before running any generated command, confirm that it matches the local operating system and that the current environment provides the necessary permissions.
